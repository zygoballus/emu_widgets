This repo is for the CMNH Minerals Web Portal: https://minerals.carnegiemnh.org/

The portal pulls data from the in-house IMu server, which provides an API to EMu.

Note that the code in `imu/lib/` comes from https://github.com/axiell/imu-api-php. The license for that code is here: https://github.com/zygoballus/emu_widgets/blob/main/imu/licence.txt.
